# KeePass Wox Plugin

[![Wox](https://img.shields.io/badge/Wox-v2.0.4+-blue.svg)](https://github.com/Wox-launcher/Wox)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey.svg)](https://github.com/Myraxion/Wox.Plugin.Keepass)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](https://github.com/Myraxion/Wox.Plugin.Keepass)

专为 [Wox](https://github.com/Wox-launcher/Wox) 启动器打造的高效、安全、纯内存驻留的 KeePass (KDBX4) 凭据检索插件。

---

## ✨ 特性亮点

- ⚡ **智能相关度检索**：支持对条目标题、用户名、网址、标签及备注进行模糊与精准匹配，结合标题匹配层级与字段齐全度（0~6 分增量加分）实现最精准直觉排序。
- 🔒 **严格内存安全**：遵循零磁盘持久化原则，主密码、派生密钥与解密后的数据库对象仅在进程内存中保存，绝不落盘、绝不记录明文日志。
- ⌨️ **安全模拟按键打字**：针对安全输入框或防剪贴板监控场景，支持直接模拟键盘键入凭据；Windows 采用 Win32 `SendInput` Unicode 直接上屏，彻底免疫中文输入法候选框拦截与乱码；凭据仅经由标准输入（`stdin`）管道流式传输，绝不暴露至命令行参数。
- 🎛️ **双输出模式随心切换**：支持“剪贴板模式”与“模拟打字模式”切换，回车默认动作与快捷键（`mod+c`、`mod+p`、`mod+u`、`mod+t`、`mod+o`）自适应调整，未填写的空字段动作自动精简。
- 📑 **Wox 原生 List 预览面板**：采用 Wox 原生 List 控件重构右侧预览面板，与客户端主题浑然一体；逐行清晰呈现凭据详情、掩码及状态 Tails，自动隐藏空字段，底部展示群组路径与最后修改时间。
- 🕒 **实时中央时钟 TOTP 支持**：严格遵循 KeePassXC 标准（`otp` 字段中的 `otpauth://` URI），支持 RFC 6238 标准动态验证码及 Steam Guard 令牌；采用共享中央壁钟定时器动态刷新剩余有效秒数，非活动时完全零资源轮询。
- 🌍 **外部化双语国际化**：内置 `lang/zh_CN.json` 与 `lang/en_US.json` 独立语言包，设置项、动作名称、提示文本全量本地化，并具备健壮的默认英文回退机制。
- 🔍 **结构化字段检索语法**：支持 `u:`、`t:`、`url:`、`g:`（及全角 `u：` 等）前缀精准检索，完整支持带空格的双引号短语（如 `u:"John Doe"`）。
- ⏱️ **空闲自动锁定与文件监听**：支持自定义空闲超时自动安全锁定；后台实时监听 `.kdbx` 数据库文件改动，外部多设备同步（如 Syncthing、OneDrive）时自动安全锁库。
- 🚫 **细粒度排除规则**：支持通过标签或群组规则排除特定条目（如废纸篓、归档分组）。
- 🌐 **跨平台纯 WASM 架构**：采用纯 WebAssembly 实现 Argon2 密钥派生与内存 Base64 图标流式传输，无本地 C++ 编译依赖，Windows、macOS、Linux 体验高度一致。

## 📦 安装

### 方式一：通过 Wox 包管理器安装（推荐）

在 Wox 搜索框中执行：

```text
wpm install KeePass
```

### 方式二：手动安装

1. 从 [Releases](https://github.com/Myraxion/Wox.Plugin.Keepass/releases) 下载最新的 `wox.plugin.keepass.wox` 安装包。
2. 在 Wox 设置中选择从文件安装，或将解压内容放置在 Wox 插件目录中。

---

## ⚙️ 配置说明

安装完成后，请进入 **Wox 设置** -> **插件** -> **KeePass** 进行基础配置：

| 配置项                 | 键名 (`Key`)      | 类型     |  必填  | 默认值      | 说明                                                                          |
| :--------------------- | :---------------- | :------- | :----: | :---------- | :---------------------------------------------------------------------------- |
| **KeePass 数据库路径** | `kdbxFilePath`    | 单行文本 | **是** | `空`        | 本地 `.kdbx` 数据库文件的绝对路径                                             |
| **密钥文件路径**       | `keyFilePath`     | 单行文本 |   否   | `空`        | 可选的 `.key` 或密钥文件绝对路径                                              |
| **输出模式**           | `outputMode`      | 下拉单选 |   否   | `clipboard` | 回车及核心输出模式。可选 `clipboard`（复制到剪贴板）或 `type`（模拟按键打字） |
| **自动锁定超时 (秒)**  | `autoLockTimeout` | 整数     |   否   | `900`       | 数据库空闲自动锁定的时间（秒）。默认 900 秒（15 分钟），设为 `0` 则不自动锁定 |
| **排除规则**           | `excludeRules`    | 单行文本 |   否   | `空`        | 逗号分隔的排除规则，如 `g:"Recycle Bin", t:Trash`                             |

## 🚀 使用指南

### 1. 触发插件

插件默认触发关键字为 `kp` 或 `keepass`。

### 2. 解锁数据库

在搜索框输入主密码并按 `Enter` 键即可完成解锁：

```text
kp 你的主密码
```

> **说明**：为了防止在连续输入密码时频繁触发计算耗时的 Argon2 / AES-KDF 密钥派生算法导致 UI 冻结，插件采用**显式回车解锁**机制；解锁成功后，搜索框内的明文密码将被自动清除。

### 3. 快速锁定

如需立即手动锁定数据库，输入：

```text
kp lock
```

### 4. 检索条目

解锁后即可直接输入关键词进行模糊匹配搜索：

```text
kp github
```

#### 高级字段前缀语法

支持在搜索词中添加特定字段前缀实现精准定位，多个条件以空格分隔；包含空格的值可使用双引号包裹：

| 语法前缀     | 含义             | 示例                              |
| :----------- | :--------------- | :-------------------------------- |
| `u:<用户名>` | 按用户名搜索     | `kp u:admin` 或 `kp u:"John Doe"` |
| `url:<网址>` | 按网址搜索       | `kp url:github.com`               |
| `t:<标签>`   | 按标签过滤       | `kp t:server`                     |
| `g:<群组>`   | 按群组路径过滤   | `kp g:"Work/Accounts"`            |
| 组合查询     | 任意条件自由组合 | `kp github u:myname t:dev`        |

#### 选中文本上下文唤醒 (Selection Query)

在外部任意应用程序或浏览器中鼠标划选 URL 或域名（例如选中 `github.com` 或 `https://gitlab.com`），直接呼出 Wox，插件会自动识别有效网址并智能提取主机名，优先推荐该站点绑定的凭据条目，实现一键登录填充。

### 5. 输出模式与操作快捷键

插件提供两种核心输出模式（可在设置中的 `outputMode` 切换），回车键与全局快捷键会自动自适应：

#### 模式一：剪贴板模式 (`clipboard`，默认)

适合日常复制粘贴工作流。

| 快捷键 (Win/Linux) | 快捷键 (macOS) | 动作             | 行为说明                                         |
| :----------------- | :------------- | :--------------- | :----------------------------------------------- |
| `Enter`            | `Enter`        | **复制密码**     | 默认项，将解密后的密码写入系统剪贴板并关闭窗口   |
| `Ctrl + P`         | `Cmd + P`      | **模拟键入密码** | 隐藏 Wox 并延时 150ms 自动在目标窗口键入密码     |
| `Ctrl + U`         | `Cmd + U`      | **复制用户名**   | 将用户名复制到系统剪贴板                         |
| `Ctrl + T`         | `Cmd + T`      | **复制 TOTP**    | 计算当前动态口令并写入剪贴板（支持 Steam Guard） |
| `Ctrl + O`         | `Cmd + O`      | **打开网址**     | 在系统默认浏览器中打开该条目绑定的 URL           |

#### 模式二：模拟打字模式 (`type`)

适合在受控环境、远程桌面、禁用粘贴的安全输入框或防止剪贴板窃听时使用。

| 快捷键 (Win/Linux) | 快捷键 (macOS) | 动作               | 行为说明                                             |
| :----------------- | :------------- | :----------------- | :--------------------------------------------------- |
| `Enter`            | `Enter`        | **模拟键入密码**   | 默认项，隐藏 Wox 并延时 150ms 自动在目标窗口键入密码 |
| `Ctrl + C`         | `Cmd + C`      | **复制密码**       | 将解密后的密码备选复制到系统剪贴板                   |
| `Ctrl + U`         | `Cmd + U`      | **模拟键入用户名** | 隐藏 Wox 并在目标窗口自动键入用户名                  |
| `Ctrl + T`         | `Cmd + T`      | **模拟键入 TOTP**  | 隐藏 Wox 并在目标窗口自动键入当前最新 TOTP 口令      |
| `Ctrl + O`         | `Cmd + O`      | **打开网址**       | 在系统默认浏览器中打开该条目绑定的 URL               |

> **💡 贴心设计**：
>
> - **动态动作精简**：条目若缺失某字段（如无用户名、未配置 TOTP 或无 URL），动作列表中自动隐藏对应项；若条目无密码，回车默认动作自动顺延至首个可用项。
> - **动作面板随时查看**：选中任意条目按 `Tab` 键即可展开全部可用动作列表。
> - **输入法免干扰**：在 Windows 平台下，模拟打字通过底层 Win32 `SendInput` Unicode 事件直接上屏，目标前台窗口无论处于中文还是英文输入法状态均不会被拼音候选框拦截，确保密码 100% 准确输入。

## 🚫 排除规则设置

可在插件设置的 **排除规则** (`excludeRules`) 中指定需要忽略的群组或标签，多条规则使用半角逗号 `,` 分隔：

- **排除特定群组**：使用 `g:` 前缀，包含空格时用引号包裹，如 `g:"Recycle Bin"`、`g:Archive`
- **排除特定标签**：使用 `t:` 前缀，如 `t:Trash`、`t:Deprecated`

**示例配置**：

```text
g:"Recycle Bin", g:Trash, t:Hidden
```

## 🛡️ 安全设计

1. **纯内存驻留 (In-Memory Only)**：主密码、派生密钥及解密后的数据库对象均仅保存在 Node.js 运行时内存中，绝不写入磁盘缓存或持久化配置。
2. **输入框即时擦除**：解锁成功后通过 Wox `api.ChangeQuery` 立即覆写搜索框输入，避免主密码停留在前台。
3. **文件变动感知**：监听数据库文件变动与修改时间戳（mtime），一旦检测到外部同步软件（如 Syncthing、Dropbox、OneDrive）修改了数据库，立即销毁内存会话并锁定。
4. **内存图标流**：自定义条目图标直接以内存 Base64 Data URI 形式加载渲染，绝不向磁盘写出任何缓存图标文件，避免服务身份足迹泄露。
5. **日志脱敏**：任何凭据、派生密钥或解密数据绝不打印至 Wox 日志。
6. **键盘模拟安全通道 (Stdin Pipeline Injection)**：模拟打字时，敏感凭据与口令严格通过跨平台子进程标准输入（`stdin`）管道直接传输，绝不作为命令行参数传递（杜绝进程参数监控与系统审计泄露），且在 Windows 平台绕过输入法拼音组合，绝不污染或落盘。

## 🛠️ 本地开发与构建

### 准备环境

- Node.js (推荐 v20+)
- pnpm
- Make

### 常用命令

```bash
# 1. 安装项目依赖
make install

# 2. 运行代码检查
make lint

# 3. 运行自动化测试套件
make test

# 4. 构建插件代码 (ncc + babel 输出到 dist/)
make build

# 5. 持续监听与热编译开发
make dev

# 6. 打包为 wox.plugin.keepass.wox
make package
```
